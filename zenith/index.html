For your agents

What zenith knows, your agents know.

Every 10 minutes zenith writes a Markdown brief of everything it knows, one file per project. Any agent can read it, and act through zenith while it runs.

  • To read: zenith_brief, zenith_project, zenith_document, zenith_search_notes, zenith_read_note.
  • To act: zenith_now, zenith_delegate to start another agent in a project, zenith_agent, zenith_done.
  • It asks first. The agent drafts, branches and proposes; it asks before sending, paying, deleting or deploying.

Quick start

Running in a minute.

You need macOS or Linux, Node.js 22.16+ and git. The first launch opens a welcome in six short steps: language, name and city, your projects (found in your code folder), your agent and its team, and their routines. No file to edit.

On a Mac, npm run mac:install builds zenith.app, a native window with a translucent sidebar, native menus, notifications and a Dock badge when a service goes down, and keeps the server running in the background.

git clone https://github.com/ludovic111/zenith.git
cd zenith
npm install
npm run dev          # http://127.0.0.1:4748

# the coding workspace, once
npm run code:build

# the Mac app
npm run mac:install

zenith's interface is Next.js and React today. Its coding-agents server and Mac app are being rewritten in Rust, like the rest of lsuite.

Privacy

It knows a lot. It tells no one.

Local only

127.0.0.1, nothing else

The server listens on your machine only and rejects any other host name, so a web page cannot reach it either.

Keys

Stay server-side

API keys live in a git-ignored file and are only used for the calls you configured. Nothing goes to a third party otherwise.

Contributing

Checked before you push

npm run privacy scans every tracked file for your identifying values and secrets, and can run before each push.

Support

Free, local, yours.

zenith is MIT licensed, runs on your machine and sells nothing. If it keeps your projects on track, sponsoring keeps it moving.
