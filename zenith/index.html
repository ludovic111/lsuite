Code with agents.
Stay in the loop.

zenith is a Mac app for coding with agents. It runs Claude Code and Codex in your projects: threads you follow and steer, approvals, plans, diffs, terminals, worktrees, git and pull requests, and what it all costs. On your machine, with your own subscriptions.

What you get

Every agent session, in one window.

One thread per task, in the project it belongs to. You see what the agent reads, runs and changes, and you can step in at any point.

Threads

Follow and steer

One conversation per task, with Claude Code or Codex. Approvals, plan mode, interrupts, follow-ups while it works, images in your messages.

Code

See every change

Diffs per turn and per thread, checkpoints you can revert to, file search. Nothing lands without you seeing it.

Worktrees

Tasks side by side

A git worktree per thread, so agents work in parallel without stepping on each other, and integrated terminals in each one.

Git & PRs

Ship in one step

Commit, push and open a pull request at once, with messages written for you. Review pull requests from GitHub, GitLab, Azure DevOps, Forgejo or Bitbucket.

Sessions & costs

Know what it costs

Every Claude Code and Codex session, in zenith or in your terminal: cost and tokens, spending by day and by model, your plan limits.

Mac app

A real Mac window

A translucent sidebar, traffic lights in the title bar, light and dark appearance, native menus and notifications.

For your agents

Each thread hands its agent zenith.

Every thread gives its agent zenith's MCP server at /mcp, with a credential that only stands for that thread. Nothing to install or configure.

  • Pull requests: the agent links each pull request it opens to its thread, so you find them, and their state, where the work happened.
  • Your own CLIs: agents run with the claude and codex you already have, on your Claude and ChatGPT subscriptions.
  • You approve: commands and edits wait for you unless you allow them, and plan mode lets an agent propose before it touches anything.
# What an agent in a zenith thread can call
link_pull_request           # right after it opens one
list_thread_pull_requests   # what this thread opened, and its state
unlink_pull_request         # after closing one by mistake
Quick start

Built on your Mac, in a few minutes.

You need macOS, Rust, Node.js 22.16+ (to build the interface) and git. Optional: the GitHub CLI logged in, Claude Code and/or Codex.

npm run mac:install builds zenith, installs zenith.app and keeps its server running in the background on 127.0.0.1:4747, so agents keep working when the window is closed. Run it again after pulling changes. Your threads and settings live in ~/.zenith/code; npm run mac:uninstall removes the app.

git clone https://github.com/ludovic111/zenith.git
cd zenith
npm install
npm run mac:install

No release to download yet: zenith 0.1 is built from source.

How it is built

A Rust server, a Tauri window.

zenith's interface is zenith code, a fork of T3 Code (MIT). Its server has been ported to Rust and is checked against the original TypeScript one by golden tests.

zenith's parts
PartWhat it is
Servercrates/zenith-code, in Rust: the API the interface talks to, an event-sourced SQLite store, the Claude Code and Codex drivers, git, worktrees, checkpoints, terminals, pull requests, usage and MCP.
Mac appcrates/zenith-app: zenith.app, a Tauri window around the interface.
Interfacecode/apps/web: the React web app from zenith code.
Privacy

Your code stays on your Mac.

Local only

127.0.0.1, nothing else

The server answers on your machine only, and the interface signs in with a one-time pairing token that the app mints itself.

Your subscriptions

Your agents, your account

Agents run with your own claude and codex CLIs and subscriptions. zenith sends your code nowhere else.

Contributing
