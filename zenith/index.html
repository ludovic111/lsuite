New in 0.2

A native window, and a download that updates itself.

0.2 rewrites zenith's window in Rust with GPUI: no web view, on the lsuite design system. Everything it does is now a command your agents can call, and it comes as a signed app that keeps itself up to date.

Window

Native, in Rust

Written with GPUI: the sidebar on the macOS material, threads by status, the agent's work grouped into one line per turn, approvals and questions answered in place, plans to implement in one click, diffs, a command palette (⌘K), light and dark.

Git and terminals

Where the thread works

A git bar in each thread (changes, ahead and behind, its pull request) with commit, push and open-a-pull-request in one step, terminals in a panel (⌘J), and the project's scripts one click away.

AI control

52 commands, three ways in

Every action is a named command shared by the window, zenith-cli and zenith-mcp: start threads, approve, answer, commit, run tests in a terminal and read the output. Settings › Agents decides how much an agent may do.

Updates

Signed, in one click

Notarized for macOS (Apple silicon and Intel), with a Linux build. zenith checks GitHub for a new release, verifies its signature and swaps itself in place; the app sets up its own server.

lsuite

Your other apps, for your agents

zenith lists the lsuite apps you have installed and hands their MCP servers to the agents of its threads, so an agent coding in zenith can drive your music and video apps too.

Messages

Images in your messages

Paste a screenshot or attach images with the paperclip: they go to the agent with your message.

What you get

Every agent session, in one window.

One thread per task, in the project it belongs to. You see what the agent reads, runs and changes, and you can step in at any point.

Threads

Follow and steer

One conversation per task, with Claude Code or Codex. Approvals, plan mode, interrupts, follow-ups while it works, images in your messages.

Code

See every change

Diffs per turn and per thread, checkpoints you can revert to, file search. Nothing lands without you seeing it.

Worktrees

Tasks side by side

A git worktree per thread, so agents work in parallel without stepping on each other, and integrated terminals in each one.

Git & PRs

Ship in one step

Commit, push and open a pull request at once, with messages written for you. Review pull requests from GitHub, GitLab, Azure DevOps, Forgejo or Bitbucket.

Every Claude Code and Codex session, in zenith or in your terminal: cost and tokens, spending by day and by model, your plan limits.

For your agents

Every action is a command your agents can call.

Starting a thread, answering an approval, reading a diff: each is a named command, the same in the window, in zenith-cli and in zenith-mcp. Every thread also hands its agent zenith's own MCP server, and those of the other lsuite apps you have installed.

  • Drive zenith: claude mcp add zenith -- …/zenith-mcp --live lets any agent start threads, wait for them and answer them. Settings › Agents decides how much it may do.
  • Pull requests: the agent in a thread links each pull request it opens to its thread, so you find them, and their state, where the work happened.
  • Your own CLIs: agents run with the claude and codex you already have, on your Claude and ChatGPT subscriptions.
  • You approve: commands and edits wait for you unless you allow them, and plan mode lets an agent propose before it touches anything.
# zenith-cli, or the same tools through zenith-mcp
zenith-cli project.overview
zenith-cli thread.new --projectId … \
  --prompt "Add a dark mode" --wait
zenith-cli thread.approve --threadId … --decision accept
zenith-cli thread.diff --threadId …
Download

Download zenith

Unzip it, move zenith.app to Applications and open it: it sets up its server (in the background on 127.0.0.1:4747, so agents keep working when the window is closed) and keeps itself up to date. zenith-cli and zenith-mcp are inside the app.

macOS · Apple silicon.zip · signed and notarized macOS · Intel.zip · signed and notarized Linux · x86-64.tar.gz

All releases. You need Claude Code and/or Codex signed in; the GitHub CLI logged in for pull requests. Your threads and settings live in ~/.zenith/code.

Or build it from source on a Mac with Rust, Xcode's command line tools and git (Node.js 22.16+ for the web interface, optional):

git clone https://github.com/ludovic111/zenith.git
cd zenith
npm run mac:install

npm run mac:install installs zenith.app, links zenith-cli and zenith-mcp into ~/.local/bin; npm run mac:uninstall removes it.

How it is built

A Rust server, a native window.

zenith grew out of zenith code, a fork of T3 Code (MIT). Its server has been ported to Rust and is checked against the original TypeScript one by golden tests; its window is native Rust too.

zenith's parts
PartWhat it is
Servercrates/zenith-code, in Rust: the API the interface talks to, an event-sourced SQLite store, the Claude Code and Codex drivers, git, worktrees, checkpoints, terminals, pull requests, usage and MCP.
Windowcrates/zenith-app: zenith.app, written in Rust with GPUI, on the lsuite design system.
Commandscrates/zenith-commands: every action as a named command, shared by the window, zenith-cli and zenith-mcp, with signed updates and lsuite discovery.
Web interfacecode/apps/web: the React web app from zenith code, for zenith in a browser.
Privacy

Your code stays on your Mac.

Local only

127.0.0.1, nothing else

The server answers on your machine only. The app, its CLI and its MCP server sign in with a session kept private on your Mac; the browser gets a one-time pairing token.

Your subscriptions

Your agents, your account

Agents run with your own claude and codex CLIs and subscriptions. zenith sends your code nowhere else.
