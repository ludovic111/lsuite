What you get

Every agent session, in one window.

One thread per task, in the project it belongs to. You see what the agent reads, runs and changes, and you can step in at any point.

Threads

Follow and steer

One conversation per task, with Claude Code or Codex, sorted by status. Approvals, plan mode, interrupts, images in your messages.

Code

See every change

Diffs per turn and per thread, checkpoints you can revert to, file search. Nothing lands without you seeing it.

Worktrees

Tasks side by side

A git worktree per thread, so agents work in parallel without stepping on each other, with terminals (⌘J) and project scripts.

Git and PRs

Ship in one step

Commit, push and open a pull request at once, with messages written for you, and the pull request linked to its thread.

Sessions and costs

Know what it costs

Every Claude Code and Codex session on the computer, in zenith or your terminal: tokens and cost by day, by project and by model.

Anywhere

A server on your tailnet

Run zenith's server on a Linux box at boot and pair your Mac with it over Tailscale; the window, CLI and MCP drive its threads.

For your agents

Every action is a command your agents can call.

Starting a thread, answering an approval, reading a diff: each is a named command, the same in the window, in zenith-cli and in zenith-mcp. Every thread also hands its agent zenith's own MCP server and those of the other lsuite apps you have installed.

  • Your own CLIs: agents run with the claude and codex you already have, on your Claude and ChatGPT subscriptions.
  • You approve: commands and edits wait for you unless you allow them, and plan mode lets an agent propose before it touches anything.
# zenith-cli, or the same tools through zenith-mcp
zenith-cli thread.new --projectId … --prompt "Add a dark mode" --wait
zenith-cli thread.approve --threadId … --decision accept
zenith-cli thread.diff --threadId …
zenith-cli git.commit --threadId … --action commit_push_pr
zenith-cli lsuite.run --app kimchi --command clip.addText \
  --params '{"text":"Hello","start":0,"duration":3}'

# any agent drives zenith
claude mcp add zenith -- /Applications/zenith.app/Contents/MacOS/zenith-mcp --live
