Score the night-market cut with an 8-bar lo-fi bed, add a rain shot at the end, render it.

On it. Writing the bed in ryolune first, then the shot and the render in kimchi.

ryolune session.overview ✓ 3 tracks · 92 bpm

ryolune track.add --kind midi --name Keys --instrument "E-Piano Mk I" ✓

ryolune clip.create --trackId Keys --lengthBars 8 --notes […] ✓ 32 notes

ryolune session.exportAudio --path bed.flac ✓ FLAC · 24-bit

kimchi generate fal fal-ai/kling-video/v3/pro/text-to-video "Rain on neon asphalt" --video ✓

kimchi render night-market.json night-market.mp4 --quality high ✓ H.264

Done. The bed is one undo away in ryolune if you want another take.

Agent-native

Built for agents, from the first line.

Most creative apps bolt a chat box onto a closed program. lsuite apps are built the other way round: every action is a command first, and the window is one client of it among others. That is what makes them drivable end to end.

Everything is a command

What you click, an agent can call: the same commands, validated the same way, from the window, a CLI or an MCP server.

One undo for everyone

Agent edits land in the same history as yours. Don't like what it did? ⌘Z. Nothing is hidden in a side channel.

Your model, your leash

Use the subscription or keys you already have (Claude Code, Codex, Anthropic, OpenAI) or a local model. Permissions decide what an agent may touch.

Rust where it counts

The engines are Rust: ryolune's audio engine and command registry, kimchi's project model, media pipeline and generation harness, zenith's server and its Mac app.

Plug in your agent

One line per app, in Claude Code, Codex or any MCP client.

The agent you already use gets the whole app as tools. ryolune connects to the open song with --live, so you see every edit happen in the window.

# ryolune: the open song, live
claude mcp add ryolune -- /Applications/ryolune.app/Contents/MacOS/ryolune-mcp --live

# kimchi: headless generation and rendering
kimchi generate fal fal-ai/flux-2-pro "Night market, rain, neon"

# zenith: nothing to add, each thread hands its agent /mcp
