Editing

A real editor underneath.

kimchi started as a fork of OpenCut and was rewritten from the ground up in Rust. The interface is thin: every edit is plain data applied by the Rust core, and the window renders what Rust returns.

  • Multi-track timeline with video, image, text, solid and audio clips.
  • Split, trim, ripple delete, duplicate, cross-track moves, snapping and markers.
  • Per-clip transform (position, scale, rotation, opacity, fit), speed, fades and volume.
  • Live preview compositor with on-canvas move and scale handles.
  • Snapshot undo and redo for every edit, and autosave.
  • Export to MP4 (H.264), HEVC, ProRes, WebM, GIF or audio only, through one ffmpeg filter graph. ffmpeg is bundled.
Models

Your keys, or nothing leaves your machine.

Keys live in your OS keychain and are only sent to the provider they belong to. Model lists are fetched live, and every model declares what it can do, so the generate panel only shows controls that apply.

Your own ComfyUI workflows become models.

Export a workflow in API format into ~/Documents/kimchi/comfyui-workflows. Each file becomes a model. Put placeholders in any string input and kimchi fills them in; a workflow with a video save node is treated as a video model.

# placeholders kimchi fills in
{{prompt}} {{negative_prompt}} {{seed}}
{{width}} {{height}} {{steps}} {{cfg}} {{denoise}}
{{duration}} {{fps}} {{frames}}
{{image}} {{start_image}} {{end_image}}   # uploaded for you
Agents and scripts

The engine, without the window.

The kimchi command runs the same Rust harness and renderer as the app: list providers and models, generate with any of them, and render a project headless. Projects are plain JSON and every edit is plain data, so an agent can read and write them directly.

An MCP server, so Claude Code, Codex and any MCP client can drive the open project live, is the next step on the way to the lsuite standard.

# what is ready, and what each provider offers
kimchi providers
kimchi models fal

# generate: images, or video with --video
kimchi generate fal fal-ai/flux-2-pro "Night market, rain, neon" --aspect 16:9 --count 2
kimchi generate fal fal-ai/kling-video/v3/pro/image-to-video "Slow push in" \
    --video --image frame.png --duration 5

# render a project, no window needed
kimchi render night-market.json night-market.mp4 --format mp4 --quality high
