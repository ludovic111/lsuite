kimchi

Cut it, or prompt it
onto the timeline.

kimchi is a desktop video editor with a built-in harness for image and video models. Prompt a shot straight onto the timeline, animate a frame you like, extend a clip from its last frame or bridge two shots with a generated transition, then cut, trim and export it like any other footage. Motion design like After Effects and 3D like Blender are built in, and captions are transcribed on your computer.

3D modelling

Shapes you make

Turn any object into a mesh and extrude, inset, bevel, loop cut, subdivide, bridge or spin it. Extrude logos from SVG paths, lathe profiles, draw tubes along curves, import OBJ, STL and glTF.

Modifiers

A stack that stays editable

Subdivision, mirror, array, bevel, solidify, boolean, displace, twist, bend, wave, wireframe, explode and build, every value animatable, applied whenever you like.

Light and render

Spot and area lights with soft shadows, skies and 360° panoramas, glass, clear coat and procedural marble, wood or cells. Depth of field, bloom and motion blur; true refraction with the path tracer.

Motion design

Like After Effects

Nested compositions with time remapping, parenting and nulls, feathered masks, track mattes, adjustment layers, 34 effects, repeaters and other shape operators, text animators, text on a path, particles.

Expressions

Editing

A real editor underneath.

kimchi started as a fork of OpenCut and was rewritten from the ground up in Rust. The interface is thin: every edit is plain data applied by the Rust core, and the window renders what Rust returns. One compositor draws the preview and the export, so what you see is what you get.

  • Multi-track timeline with video, image, text, solid and audio clips.
  • Split, trim, ripple delete, duplicate, copy and paste, cross-track moves, snapping and markers.
  • Per-clip transform (position, scale, rotation, opacity, blur, fit), keyframed or not, speed, reverse, freeze frames, fades and volume.
  • Transitions, colour and captions on the timeline, with the sound crossfading under every transition.
  • Live preview with on-canvas move and scale handles; press ? for every shortcut.
  • Snapshot undo and redo for every edit, and autosave.
  • Export to MP4 (H.264), HEVC, ProRes, WebM, GIF or audio only, on the GPU where the computer can. ffmpeg is bundled.
Models

Your own ComfyUI workflows become models.

Export a workflow in API format into ~/Documents/kimchi/comfyui-workflows. Each file becomes a model. Put placeholders in any string input and kimchi fills them in; a workflow with a video save node is treated as a video model.

# placeholders kimchi fills in
{{prompt}} {{negative_prompt}} {{seed}}
{{width}} {{height}} {{steps}} {{cfg}} {{denoise}}
{{duration}} {{fps}} {{frames}}
{{image}} {{start_image}} {{end_image}}   # uploaded for you
Agents and scripts

Your AI can cut too.

Everything you can do in the window is a named command, and the window, the built-in agent, kimchi-cli and kimchi-mcp all use the same ones, with one undo history. Claude Code, Codex or any MCP client can drive the open project live; scripts can work on a project file without the app.

The Agent panel runs the model you already have (Claude Code, Codex, an Anthropic or OpenAI key, or a local Ollama model), shows one card per command and reverts a whole run in one click. Ask it for a title sequence and it writes the motion scene, then looks at the frames it made. You decide what agents may touch: files, projects, generation, settings. And kimchi hands a cut to ryolune to score it, then takes the music back.

# Claude Code drives the running app
claude mcp add kimchi -- /Applications/kimchi.app/Contents/MacOS/kimchi-mcp --live

# or any script, on the app or a project file
kimchi-cli project.overview
kimchi-cli generate.extendClip --clipId "Night market" --prompt "slow push in"
kimchi-cli --file cut.json clip.addText text="Opening title" start=0
kimchi-cli motion.addTemplate template=title3d values='{"text":"NIGHT MARKET"}'
kimchi-cli captions.transcribe
kimchi-cli export.start path=cut.mp4 quality=high wait=true

# send the cut to ryolune to score it
kimchi-cli handoff.toRyolune

  1. 0.74 Oct 2026

    3D like Blender, motion design like After Effects

    • 3D modelling: editable meshes, a modifier stack, extruded logos, lathes, curve tubes, OBJ and STL models.

  2. 0.63 Oct 2026

    Steadier, with logs, crash reports and what's new

    • About seventy fixes from a bug hunt over every part of kimchi: failed edits leave nothing half-done, duplicates keep their media, an agent's stopped batch can't hang or undo your edits, and shortcuts never fire while you type.
    • Logs and crash reports in Settings › Diagnostics, including runs that didn't quit properly, and Help › Report a Problem. Nothing is sent anywhere.
    • What's new after each update, and from the Help menu any time.
    • Updates every few hours, installed by themselves if you like, and on Windows through the signed installer.
    • Media from phones and long recordings: upright portrait photos, HDR tone-mapped, transparent WebM, hundreds of cuts from one file, exact NTSC rates, captions in any encoding.
    • Window buttons on Windows and Linux, Ctrl instead of ⌘ there, and ffmpeg, Claude Code and Codex found wherever they are installed.
