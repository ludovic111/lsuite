Apps

Install once. Stay up to date.

Each app comes from its own GitHub releases, and nothing is installed until it checks out against the release key built into the launcher. A new version is unpacked next to the old one and swapped in; if anything fails, the old copy stays.

Signed

Verified before anything is replaced

Every download is checked against the app's signature (minisign or Ed25519) before it touches your apps. A file that doesn't match is thrown away.

Careful

Your work comes first

An open app is never replaced or removed. Removing an app keeps its documents, settings and data, and copies you built from source are shown, never touched.

Linux and macOS

Where apps belong

/Applications on macOS, ~/.local/share/lsuite/apps with a menu entry on Linux (Windows is coming soon). The launcher updates itself the same way.

Plugins

Every app's plugins, in one place.

From its next release, the launcher's Plugins area lists the plugins installed for each app and hands a plugin request to the right app's agent: describe it, and the agent writes it in Rust, builds it and loads it. How plugins work.

Agent and scripts

Your agent can set up the suite.

Every action is a command, the same from the window, lsuite-cli and lsuite-mcp: install an app, update them all, list the plugins.

You decide what an agent may do. Installing is on; removing apps and plugins stays off until you turn it on in Settings › Agents.

# install or update from a script
lsuite-cli apps.install app=kimchi
lsuite-cli apps.updateAll

# or hand it to Claude Code
claude mcp add lsuite -- /path/to/lsuite-mcp

Questions

Before you install.

Do I need the launcher to get the apps?

Yes: the ready-made builds of the four apps come through it. Install the ones you want and update them all at once. Their source stays open (MIT), so you can always build an app yourself.

Do I need an account?

No. lsuite is free, with nothing to sign in to: the launcher, the apps, their updates and their plugins.

How do I know a download is genuine?

The launcher carries each app's release key and checks every file's signature before it installs. If a signature doesn't match, nothing is replaced. Its own updates are signed the same way.

Will it touch the copies I built myself?

No. Copies outside the usual places, such as builds from source, are listed and left alone.

Does it send anything about me?

No telemetry. It asks lsuite.xyz for the apps and their builds, and GitHub for its own updates. Nothing else.
